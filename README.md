# MSGI

MSGI (Model satellite glaciation intercomparisson) is a project comparing cloud glaciations observed from satellites to those occuring in climate models.

It enables an equivalent time-resolved analysis between clouds observed in the CLAAS-3 dataset (based on MSG SEVIRI measurements) and ICON model output. The processing is split into two modes - model and observations. Both rely on cloud tracking and postprocessing from `glaciation_time_estimator` (GTE).
